## 🧩 시나리오

요일 번호(`num`)를 입력받아 해당 요일명을 출력한다.

- 1 → 월요일  
- 2 → 화요일  
- 3 → 수요일  
- 4 → 목요일  
- 5 → 금요일  
- 6 → 토요일  
- 7 → 일요일  
- 그 외 → `"잘못된 입력입니다!"`

---

## 📌 입력/출력 정리

### 입력(Input)
- 요일 번호 (정수)
  
### 출력
- `num`에 해당하는 요일명 출력 (월~일)
- 범위를 벗어나면 `"잘못된 입력입니다!"`

### 상태 (계속 들고 있어야 하는 값)
- `num` (요일 번호)

---

## 🔎 조건 정리

### 종료 조건 (끝나는 시점)
- 정상 요일 출력 후 종료  
- (반복 버전의 경우) 올바른 입력이 들어오면 출력 후 종료

### 분기 조건 (갈라지는 기준)
- `case 1` : 월요일
- `case 2` : 화요일
- `case 3` : 수요일
- `case 4` : 목요일
- `case 5` : 금요일
- `case 6` : 토요일
- `case 7` : 일요일

### 예외 / 에러 조건
- 1~7이 아닌 값 입력 시  
  → `"잘못된 입력입니다!"` 출력

---

## 🔁 로직 흐름 설계

1. 요일 번호(`num`)를 입력받는다.
2. `switch(num)`로 분기 처리한다.
3. 1~7이면 해당 요일명을 출력한다.
4. 그 외 값이면 `"잘못된 입력입니다!"`를 출력한다.
5. 프로그램을 종료한다.
