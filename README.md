## 📌 프로젝트 소개

이 저장소는 **FlowChart 기반으로 설계를 진행한 Java 실습 코드**를 정리한 것입니다.

요일 번호를 입력받아 그에 해당하는 요일명(월요일~일요일)을 출력하는 프로그램을 구현하면서,  
다양한 조건 분기 방식(if문, switch문, default 활용, 반복문)을 비교하고 설계 중심 사고를 연습했습니다.
